# Java Console-Based Calculator

A simple console-based calculator application developed in Java. It allows users to perform basic arithmetic operations by taking inputs and operator choices via the command line.

---

## 🚀 Features

- **Dynamic Arithmetic Operations:** Supports addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
- **User Input Handling:** Uses the `Scanner` class to capture user numbers and operation choices dynamically.
- **Conditional Logic:** Evaluates the selected operator using `if-else` statements to execute the correct calculation.

---

## 🛠️ Technologies Used

- **Java** (Core Java, Conditional statements, Control flow)
- **Scanner Class** (User input handling)
